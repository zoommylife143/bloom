# Bloom: Private AI Gynecology Copilot

Bloom is a privacy-first pre-visit intake and physician-brief agent, built for Boat Hackathon SF 2026 (Zoom My Life). Its AI inference runs on NY Token Exchange confidential routes, the clinical guidelines it cites come from Context.dev, and it is hosted on Boat.dev.

- Plan: see `CLAUDE.md` and `docs/STATUS.md`
- Design: https://www.figma.com/design/0lWIv5IY18QemXtzP3YaTE
- Synthetic data only. Not a medical device. Not HIPAA compliant.
