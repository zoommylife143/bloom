## Notes

- "Side sheet" in docs/02-app-flow.md vs Figma: Figma draws D03 as a fixed 424 px right column inside D02's body row (gap 24), not a modal/side sheet. Tablet stacks it below.
- TrustRow "Not exposed" variant still shows the tag text "OK" (in secondary grey, with `icon/info`). The variant name and its tag differ; confirm whether the tag should read something else.
- All four row-state variants keep the header label "brief · private demo mode" even for Dev mode, which is labelled "Route: GLM-5.3 Flash (development)" and "Not confidential". In code, the header label should come from data (call name + mode).
- The De-identification block keeps `icon/check` even in the "search failed (timeout)" state; no warning icon or color is used there.
- In the generating state the De-id title uses "searching guidelines…" while the body says "2 de-identified queries sent"; the default says "2 guideline queries". Copy is verbatim from Figma.
- Request ID "req_example_0142" and "1.8 s" are placeholder values; the Figma description says rows must show only fields the provider returns.
