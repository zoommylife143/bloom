## Layout (top to bottom)

- **Page** (`26:3`): column, main- and cross-axis centered (card centered both ways), padding `spacing/xl` 24 all sides, bg `color/bg/canvas` #fbf8f4.
  - **Sign-in card** (`26:4`): column, fixed width **480**, padding `spacing/2xl` 32, gap `spacing/lg` 16 between every child, cross-axis start (left aligned), bg `color/bg/surface` #ffffff, 1 px border `color/border/default` #dcd3c8, radius `radius/lg` 16, clip content.
    1. **Brand** row (`26:5`): row, gap `spacing/sm` 8, center aligned, hug width.
       - Logo icon, layer "Frame" (`26:6`), 24 x 24 (sparkle-like glyph in brand colour; vector, export from Figma).
       - "Bloom" wordmark text.
    2. **Title** (`26:9`): fills card width.
    3. **Banner** instance, `Type=Demo` (`I`-instance of `4:35`), full width (overrides the component's fixed 358 width).
    4. **Field label** (`26:16`).
    5. **Input** (`26:17`): row, full width, padding H `spacing/lg` 16 / V `spacing/md` 12, gap `spacing/md` 12, bg `color/bg/surface`, 1 px border `color/border/default`, radius `radius/md` 12. Contains placeholder text only (no icon). Rendered height 50 (24 line height + 2 x 12 + 2 x 1 border).
    6. **Roles** (`26:19`): column, full width, gap `spacing/md` 12.
       - **Role/Continue as patient** (`26:20`): row, full width, padding `spacing/lg` 16, gap `spacing/md` 12, center aligned, bg `color/bg/brand-subtle` #faf4f8, 1 px border `color/border/brand` #6b2d5c, radius `radius/md` 12.
         - Icon "Frame" (`26:21`) 24 x 24 (person outline, brand colour).
         - Text column (`26:24`): flex 1, gap `spacing/xs` 4: title + subtitle.
       - **Role/Continue as clinician** (`26:27`): identical structure; icon (`26:28`) 24 x 24 is a stethoscope outline.
    7. **Footer disclaimer** (`26:37`): fills card width, wraps.

The role tiles are the actions: tapping one signs in with that role (there is no separate submit Button in this frame).

## States

### Invalid code (`26:38`, `A01-invalid-code.png`), 1440 x 900

Same as default except:
- Input (`26:52`) border changes to `color/status/critical` #b42318 (bg still `color/bg/surface`).
- Input text shows the masked entered value `••••••` (six U+2022 bullets) in `color/text/secondary`, Body style.
- New error message (`26:54`) inserted directly **below the input, above Roles**, full width, Caption (DM Sans Regular 12/16), colour `color/status/critical`:
  `That code didn’t work. Check it and try again.` (note typographic apostrophe U+2019).
- Card gap stays 16, so the error text sits 16 below the input.
- Role tiles are unchanged (no disabled styling).

### Phone (`26:74`, `A01-phone.png`), 390 x 844

- Page padding still `spacing/xl` 24, content centered vertically.
- The **card chrome is removed**: the "Sign-in card" frame (`26:75`) has no bg, no border, no radius and **no padding**; content sits directly on `color/bg/canvas`.
- Content width **342** (390 - 2 x 24). Gap between children still `spacing/lg` 16.
- All children, copy and styles identical to default (Title stays Display 32/40; footer wraps).
- Breakpoint implied: below the 480 + 2 x 24 card width, render without the card (full-width column with 24 side padding).

## Notes

- The input placeholder uses `color/text/secondary`; the masked value in the error state also uses `color/text/secondary` (not primary), as in Figma.
- The logo and role icons are vector layers named "Frame" (not named icon components). Export them from Figma (`download_assets` on `26:6`, `26:21`, `26:28`) or substitute matching Material Symbols and flag it; do not hand-draw.
- No Button component is used on this screen; the role tiles are the CTAs. There is no focus/pressed state drawn for the tiles or input.
- Banner component has a fixed width of 358 in the master; every instance here overrides it to fill the parent.
