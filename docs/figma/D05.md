## Notes

- No Demo Banner on D05 (D01 has one). Follow Figma.
- Scenario cards are 212 wide fixed; 5 x 212 + 4 x 16 = 1124 fits Main's inner width (1192 - 64 = 1128). On narrower widths the Wrap reflows.
- Cards use `radius/lg` 16 (plan says doctor cards use md 12). Follow Figma.
- The `icon/alert` in the Negative test head renders red in the PNG; the icon color comes from the SVG asset, not a bound token in the code output.
- Scenario IDs S1-S10 and their descriptions match the server scenarios naming; all data is synthetic.
