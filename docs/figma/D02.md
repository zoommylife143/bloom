## Notes

- The default frame is the "draft awaiting review" state; it is the only desktop state with the DecisionBar, apart from "no guideline". Approved, edited and rejected all drop the DecisionBar entirely (no disabled bar).
- StatusChip Rejected (`25:196`) is a real variant inside the StatusChip set `4:27` (confirmed with get_metadata on the Components page); it was added later, hence the 25:x ID.
- Banner variants resolved from the Components page: inner nodes `4:52`/`4:55` belong to `Type=Verified` (4:51) and `4:42`/`4:46` to `Type=Urgent` (4:41); the screen text is an instance override. The set has four types: Demo, Urgent, Draft, Verified.
- Edited state uses the Approved chip; there is no distinct "Edited" status chip.
- Skeleton bar radius 6 is a raw value; design-tokens.json has no `radius/sm` value (figma-state lists a `radius/sm` variable, ID 2:46, value not read).
- Icon SVG colors were not exposed as tokens; icons appear to follow their label color in the screenshots (brand for active nav and Draft banner, secondary for inactive nav, verified for shield in Mode card and TrustRow).
- "dr.demo" and times are synthetic demo values; bind them to provenance data (approver, timestamp) in code.
- Overline letter spacing confirmed as 0.72 px at 12 px (6%).
