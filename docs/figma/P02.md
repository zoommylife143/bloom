## Components

- **ChatBubble** (component set `4:32`; variants `sender=Bloom` master `4:28`, `sender=Patient` master `4:30`). Column, width **280** fixed, padding H `spacing/lg` 16 / V `spacing/md` 12, radius `radius/lg` 16 (all four corners, no tail).
  - sender=Bloom: bg `color/bg/surface` #ffffff, 1 px border `color/border/default` #dcd3c8, text Body `color/text/primary`.
  - sender=Patient: bg `color/action/primary` #6b2d5c, no border, text Body `color/text/on-action`.
  - Figma description: "Intake chat message. Bloom asks one question per bubble; never shows a diagnosis."
- **QuickReply** (component `4:33`): row, padding H `spacing/lg` 16 / V `spacing/sm` 8, bg `color/bg/surface`, 1 px border `color/border/brand` #6b2d5c, radius `radius/full`, text Label `color/text/brand`. Visual height 36 (20 + 2 x 8); Figma description says "Quick-reply chip for intake answers (44px min target in code)", so pad the tap target to 44 in Flutter.
- **Button** style=Secondary (master `4:4`) — only in refused/model-error states (see below).
- Non-component patterns: Header with progress bar, Composer (pill input + round send), Trust note, Refused card, Typing indicator (vector, not a component).

## States

### waiting — `10:23`, `P02-waiting.png`
Bot is generating the next question.
- Header, Composer and Trust note identical to default (composer stays enabled, same placeholder "Type your answer").
- Messages: the same five bubbles, then
  - **Quick replies row removed**,
  - new Row/Patient (`10:66`) with ChatBubble sender=Patient "Not sure.",
  - new **Row/Typing** (`10:73`): row, align start, containing **Typing indicator** (`10:69`), a single vector 70 x 38 (three-dot bubble). Exported as an SVG asset in Figma, not a component.

### route refused — `6:87`, `P02-refused.png`
NYTE / confidential route refused; private demo mode fails closed.
- Header identical (still "Question 5 of about 10", progress 171).
- Messages: only Row/Bloom "When did your last period start?" and Row/Patient "About three weeks ago.", then a **Refused card** (`6:104`):
  - column, full width, padding `spacing/lg` 16, gap `spacing/md` 12, bg `color/status/critical-subtle` #fef3f2, 1 px border `color/status/critical` #b42318, radius `radius/lg` 16.
  - **Head** `6:105`: row, gap `spacing/sm` 8, align center. `icon/ban` 20 x 20 + title "Paused to protect your privacy" (Title 18/26, `color/status/critical`).
  - Body (`6:110`, Body Small 14/20, `color/text/primary`): "We couldn't reach a confidential AI route, so we paused instead of using a less private one. Your answers so far are saved."
  - **Button** style=Secondary, label "Try again", hug width (left aligned). Secondary = bg `color/bg/surface`, 1 px border `color/border/default`, radius full, padding 24/12, label Label `color/text/primary`.
- Composer disabled: Input bg changes to `color/bg/subtle` #f3eee7 (border unchanged), placeholder text **"Paused"**; Send bg changes to `color/bg/subtle` (icon unchanged).
- Quick replies removed. Trust note unchanged.

### model error — `23:71`, `P02-model-error.png`
Same structure as route refused (card layer is also named "Refused card", `23:86`), with different copy:
- Title: "Something went wrong on our side"
- Body: "Your answers are saved. Please try again in a moment."
- Button: Secondary "Try again".
- Same `icon/ban` 20, same critical colors, same disabled composer with "Paused".

### tablet — `23:108`, `P02-tablet.png`
768 x 1024. Same content and order as default (incl. Quick replies). Differences:
- Frame padding: horizontal **144**, vertical `spacing/xl` 24 → content column is 480 wide (768 - 2 x 144). 144 is a raw value, not a token.
- Progress fill width 240 (50% of the 480 track).
- ChatBubbles keep fixed width 280; everything else stretches to 480.
- Implementation: center the column at max width 480 for widths >= 768 (tablet breakpoint); on phone use 24 padding.

## Notes

- **Instance content vs component defaults:** the third Bloom bubble in default/waiting/tablet and the first bubble in refused/model-error have no message override; they show the ChatBubble default text "When did your last period start?". Likewise the third QuickReply has no override and shows the default "Not sure". Copy listed above is what renders.
- **Model-error title overflows**: "Something went wrong on our side" is single-line (`whitespace-nowrap`) and is clipped in the PNG ("...our si"). In code allow it to wrap.
- The model-error card layer is named "Refused card" (copied from 6:104); there is no separate error-card component and no Banner variant for these.
- Progress fill is a fixed 171 px in Figma; in code drive it from question index / estimated total (5 / 10).
- The disabled composer is a manual override (bg `color/bg/subtle`), not a component state.
- No Banner (Demo) on P02; the demo disclaimer appears on P01 and A01 only. Trust note text is the persistent privacy indicator here.
