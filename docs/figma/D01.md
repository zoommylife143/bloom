## Notes

- Banner instance has fixed width 358 (the mobile Banner default width) rather than fill. In the PNG it is a short pill under the header. Keep 358 or hug content; do not stretch to full width unless Figma changes.
- Overline letterSpacing: Figma value 6 renders as `tracking-[0.72px]` = 6% of 12px. Use letterSpacing 0.72 in Flutter.
- Raw values not bound to tokens: skeleton radius 6 (there is a `radius/sm` variable in the file, VariableID:2:46, but these bars do not use it and its value is not in `docs/design-tokens.json`), empty-state padding 24/48 and gap 8 (24 and 8 equal `spacing/xl` and `spacing/sm` but are unbound; 48 has no token).
- Table card uses `radius/lg` 16, although plan section 3 says doctor cards use `radius/md` 12. Follow Figma.
- Ghost buttons in the rows carry 24/12 padding, so the clickable label sits indented from the column's left edge (visible in the PNG).
- Sidebar Mode card text "Confidential NYTE route only · fails closed" wraps at sidebar width.
